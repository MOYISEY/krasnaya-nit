# Красная нить

Локальная доска расследования для Бахтияра и друзей: сцены, персонажи, места, выводы и направленные связи-улики. Подходит ведущим D&D, Savage Worlds и других систем; правил конкретных игр внутри нет.

**Демо:** https://moyisey.github.io/krasnaya-nit/

## Попробовать за пять минут

1. Откройте встроенное дело «Последний рейс “Чайки”». В демо 8 карточек и 7 связей, включая независимые дороги к насосной.
2. В «Проверке прочности» выберите «Пропущена улика» → «Квитанция на масло». К спасению капитана больше нет пути; приложение подсветит ключевой вывод и покажет обрыв.
3. Добавьте связи «Пустой причал» → «Гадалка у рынка» и «Гадалка у рынка» → «Восточный склад». Потеря квитанции теперь не обрывает спасение.
4. Откройте карточку, впишите отдельный текст для игроков и заметки ведущего. Пометьте карточку как раскрытую. Для раскрытой связи отметьте также оба конца.
5. Скачайте HTML-снимок игрокам. В нём физически отсутствуют скрытые карточки, заметки ведущего, внутренние ID и названия улик. Полную JSON-копию с секретами сохраните отдельно.

## Что умеет

- Создавать, редактировать и удалять карточки и направленные связи. Несколько стартов, ключевые выводы, состояния «Не раскрыто», «Раскрыто», «Недоступно».
- Перемещать карточки и обзор, менять масштаб; эквивалентный список с доступными формами и связями. На узких экранах сразу открывается читаемый список.
- Сравнивать исходную достижимость с пропуском ровно одной улики или источника. Уже недостижимые выводы перечисляются отдельно.
- Отменять и повторять последние 60 действий; сохранять дело в localStorage; импортировать и экспортировать полную JSON-копию; скачивать безопасный HTML для игроков.

## Честные границы

Это анализ записанного графа, а не прогноз того, решат ли игроки загадку. Любой один путь считается достаточным: AND/OR, броски, обязательные сочетания и временные условия не моделируются. Циклы, петли и несвязанные части допустимы.

Одна доска на браузер и адрес сайта. Очистка браузера, приватное окно или другой адрес могут лишить вас локальной копии. Квота localStorage зависит от браузера; при неудаче записи приложение предупреждает и предлагает JSON. Одновременные вкладки могут перезаписать изменения. История отмены не сохраняется после перезагрузки и не входит в JSON.

Никаких аккаунтов, AI, API, серверного хранения, аналитики или совместного редактирования. Код приложения не отправляет данные кампании. GitHub Pages получает обычный запрос загрузки сайта и может вести инфраструктурные журналы посещений. Снимок передаётся скачанным файлом и не обновляется автоматически.

**Название дела, названия раскрытых карточек и поля «Текст для игроков» считаются публичными.** Приложение не может распознать секрет, который ведущий сам записал в публичное поле. Перед скачиванием проверьте содержимое. Все названия связей всегда исключаются из игрокового экспорта, даже если связь раскрыта.

## Клавиатура и доступность

Tab выбирает элементы, Enter открывает карточку с переводом фокуса к её форме. В фокусе доски стрелки перемещают обзор, +/− меняют масштаб. Положение карточки можно задать полями X/Y. Ctrl+Z отменяет действие, Ctrl+Shift+Z повторяет; внутри текстовых полей остаются команды браузерного редактора. В «Списке» доступны все карточки, их состояния, заметки и связи. Поддерживаются reduced motion и мобильные viewport; проверка на физическом телефоне не проводилась.

## Разработка

Нужен Node.js 22+; пользовательский интерфейс не требует npm-пакетов.

```sh
npm ci
npm run dev
# http://127.0.0.1:4173
npm test
npx playwright install chromium
npm run test:e2e
npm run build
```

Для уже запущенного сервера задайте `NO_WEB_SERVER=1`. Для live-проверки задайте `LIVE_URL=https://moyisey.github.io/krasnaya-nit/`. Локальный сервер слушает только loopback. GitHub Pages публикует статические файлы из `docs/`; `npm run build` синхронизирует исходники в этот каталог. Сборка не требует платных сервисов.

## Формат и защита

Версия JSON-схемы: 1. Не более 120 карточек, 360 связей; заголовки и названия улик до 120 символов, каждый текст до 5000 символов, импорт до 8 МБ. Проверяются типы, состояния, булевы поля, числовые координаты, уникальность ID и существование концов связей. Неизвестные поля отбрасываются. Координаты ограничены ±10000. Максимальный собственный backup, включая JSON-экранированные символы, укладывается в лимит импорта.

HTML создаётся через разрешённый список публичных полей и экранирование. Экспорт не содержит скриптов; его CSP запрещает сеть и активное содержимое. Основная доска — секретная рабочая поверхность ведущего. Не показывайте её игрокам вместо снимка.

Весь код, интерфейс и небольшой детективный сюжет созданы для этого проекта. Чужие тексты rulebook, иллюстрации и ассеты не используются.
